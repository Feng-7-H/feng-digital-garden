# 个人网站（个人主页 + 数字花园）实施计划

## 概述

Web 端个人网站：以「个人主页 + 数字花园」为核心形态。包含关于我、作品展示等固定内容区，以及笔记相互关联、标签网络化的数字花园；数据存储于云端数据库（Supabase），配备独立写作后台。**权限模型**：后台与全部内容编辑仅站长本人可用（管理员邮箱+密码登录认证），前台访客免登录只读浏览，未登录访问后台重定向管理员登录页；作品详情页展示项目完整内容，头像、作品封面与内容图片上传至对象存储（Supabase Storage）。整体框架可扩展，后续新功能（评论、归档、友链等）可在此基础上增量补充。

**内容约束（CRITICAL）**：所有板块内容（个人介绍、技能、作品、笔记、标签等）均由用户主动输入，系统与开发阶段**禁止预生成任何示例数据、演示内容或占位文案**，各页面直接呈现真实空态。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 平台 | Web | 用户需求 |
| 框架 | Next.js 16 (App Router) + TypeScript | 全栈一体，内容展示 SEO 友好 |
| UI | Tailwind CSS 4 + shadcn/ui | 原型还原与组件规范 |
| 数据库 | Supabase (PostgreSQL) | 云端持久化，标签多对多关系查询能力强 |
| API | Next.js API Routes + Supabase 服务端访问 | 前后端分离，便于扩展 |
| 编辑器 | Markdown 编辑 + 实时预览 | 笔记写作主流形态，轻量可控 |
| 认证 | Supabase Auth（邮箱+密码，单管理员账号） | 实现"仅本人可编辑，访客只读"的权限模型 |
| 对象存储 | Supabase Storage | 头像、作品封面与内容图片上传 |

## 功能模块

### 1. 数据层（Supabase）
- `notes`：id / title / content(markdown) / status(draft|published) / created_at / updated_at
- `tags`：id / name / color
- `note_tags`：note_id / tag_id（多对多关联）
- `works`：id / title / subtitle / content(富文本) / link / cover_url / content_images / tags / sort_order / created_at / updated_at
- `profile`：单行表，存关于我内容（昵称、头像 avatar_url、头衔、简介、技能标签、联系方式）
- `messages`：id / name(昵称) / content(留言内容) / visitor_token(匿名访客标识) / created_at / updated_at / deleted_at(软删除标记，空=正常)（数字花园留言板：访客免登录留言；访客可修改/删除自己 30 分钟内的留言，按本机 visitor_token + 时间窗口判定；软删除保证站长可查看全部记录）
- **初始化仅建表结构，不写入任何种子/示例数据**；全部内容经后台由用户录入（留言除外——留言由访客产生）

### 2. 前台展示
- 首页：极简标语页（品牌代号 + 主题标语居中排版，无内容列表区块）
- 数字花园：标签云筛选 + 搜索 + 笔记卡片流 + **留言板（访客留下想法与见解，无需登录）**
- 笔记详情：Markdown 渲染 + 标签 + 相关笔记（按共享标签推荐）
- 关于我：个人介绍 + 作品列表 + 联系方式

### 3. 写作后台（/admin）
- 管理页内分四个 Tab：笔记 / 作品 / 关于我 / 留言
- 笔记管理列表：状态筛选、搜索、编辑、删除
- Markdown 编辑器：标题、标签选择（可新建标签）、编辑/预览、草稿与发布状态管理
- 作品管理：新增/编辑/删除作品（标题、描述、链接、封面与内容图片上传），前台点击进入作品详情页
- 关于我编辑：表单编辑头像（上传）、昵称、头衔、简介、技能标签、联系方式
- 留言管理：查看全部留言记录与内容（含访客 30 分钟内自行软删除的记录，灰色标记）、删除不当留言（硬删除，同步移除前台展示）

### 4. 管理员认证（/admin-login）
- 邮箱+密码登录（Supabase Auth），仅站长本人账号可登录
- **账号初始化采用"首次向导"（用户已确认方案 A）**：部署后站长首次访问登录页时，若系统中尚无管理员账号，页面显示「创建站长账号」表单（需同时输入初始化密钥校验，密钥随机生成并交付站长）；创建完成后该入口永久关闭，此后登录页仅支持登录。密码由 Supabase Auth 加密存储，代码中不出现明文凭证
- 未登录访问 /admin、/admin-editor 时重定向登录页；登录成功进入后台
- 前台所有页面访客免登录只读；关于我页「编辑」入口仅登录后可见

## 实施步骤

1. **阶段一：原型设计** — 加载 `design-canvas` 技能，按 web 规范产出全部页面原型（首页 / 数字花园 / 笔记详情 / 关于我 / 作品详情 / 后台列表 / 编辑器 / 管理员登录），提交用户验收
2. **阶段二：初始化项目** — `coze init` 初始化 Next.js 项目，迁移原型 `@theme` 变量至 `globals.css`
3. **数据层与认证** — Supabase 建表（notes / tags / note_tags / works / profile / messages，不预填内容数据）+ Auth 单管理员 + Storage 桶（头像/作品图片）+ API Routes（`src/lib/supabase.ts`、`src/app/api/*`）
4. **前台开发** — 首页、关于我（编辑浮动按钮仅登录可见）与作品详情页，全部呈现真实空态（`src/app/page.tsx`、`src/app/about/page.tsx`、`src/app/work-detail/page.tsx`）
5. **数字花园** — 笔记列表筛选搜索、笔记详情相关推荐与留言板（访客提交/展示/30 分钟内编辑与删除自己的留言，删除仅站长）（`src/app/garden/page.tsx`、`src/app/note-detail/page.tsx`）
6. **写作后台** — 管理员登录、管理页（笔记/作品/关于我/留言四 Tab，含图片上传与留言管理）与 Markdown 编辑器（`src/app/admin-login/page.tsx`、`src/app/admin/page.tsx`、`src/app/admin-editor/page.tsx`）
7. **验证交付** — `test_run` 静态检查 + 全部 API 冒烟测试 + 日志健康检查

##### @page(/garden) 数字花园

**核心职责**：浏览、搜索、按标签筛选所有已发布笔记，并提供访客留言板。
**访问路径**：导航直达；从首页/详情页进入。
**布局**：topbar + 标签云（当前筛选标签高亮）+ 搜索框 + 笔记卡片网格（响应式 1-3 列）+ 留言板（标题「留下你的想法」+ 留言表单（昵称/想说的话/提交按钮）+ 留言列表（新留言在前））。
**列表项字段**：标题 / 摘要 / 标签 / 更新时间。
**留言项字段**：昵称首字徽章 / 昵称 / 时间 / 内容 / 我的留言标识 / 编辑+删除按钮（本机留言且距发布 <30 分钟时显示）/ 删除按钮（仅站长）。
**状态**：
- 空态：暂无笔记，展示引导文案；留言列表为空时展示"欢迎留下您宝贵的经验分享~"
- 加载态：卡片骨架屏
- 无结果：搜索/筛选无匹配时提示

##### @page(/admin) 后台管理

**核心职责**：管理全部内容（笔记 / 作品 / 关于我 / 留言），提供入口进入编辑器。
**访问路径**：导航右侧按钮直达；未登录访问重定向 @page(/admin-login)。
**布局**：topbar + 管理对象 Tabs（笔记 | 作品 | 关于我 | 留言）+ 工具栏（新建按钮、状态筛选 Tabs、搜索框）+ 内容管理列表。
**列表项字段**（笔记 Tab）：标题 / 状态（草稿|已发布） / 标签 / 更新时间 / 操作。
**列表项字段**（作品 Tab）：封面 / 标题 / 描述 / 链接 / 操作。
**列表项字段**（留言 Tab）：昵称首字徽章 / 昵称 / 时间 / 内容 / 状态（正常 或 已删除灰色标记）/ 删除。
**作品编辑弹窗**：标题、描述、外链、封面上传、正文内容与图片上传（存对象存储），保存后前台作品详情页展示完整内容。
**关于我 Tab**：表单直接编辑（头像上传、昵称、头衔、简介、技能标签、联系方式），保存即生效。
**状态**：空态（暂无内容，引导新建；留言 Tab 空态"欢迎留下您宝贵的经验分享~"）、加载态骨架。
**弹窗 confirm-delete**：
- 标题："确认删除"
- 内容：展示将删除的笔记/作品标题或留言者昵称
- 操作：确认（删除并刷新列表）、取消（关闭弹窗）

##### @page(/admin-editor) 笔记编辑器

**核心职责**：撰写/编辑笔记，管理标签与发布状态。
