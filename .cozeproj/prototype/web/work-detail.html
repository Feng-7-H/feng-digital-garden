苔原笔记 · 本地优先的 Markdown 知识库

为长期写作者打造的桌面端知识管理工具——让每一个想法都能被安放、被连接、被再次发现。

2025-08-12 发布 桌面应用 · 独立开发（产品设计 / 全栈） 访问项目

起因：为「长期写作」做减法

过去三年，我的笔记散落在五六个工具之间——云端笔记、本地文件夹、手机备忘录各存一份，每次换工具都要迁移一次数据，写作的兴致也在一次次搬运中被消磨殆尽。我想要一个真正属于自己的「一亩三分地」：文件是纯 Markdown，数据始终在本地，检索必须足够快。

于是有了「苔原笔记」。名字取自苔原生态：表面上安静克制，土地之下却一直在缓慢而顽强地生长——这也正是长期写作本来的样子。

功能亮点

  • 本地优先：笔记以纯 Markdown 文件存储在本地目录，随时可用任何编辑器打开，不做数据绑架；
  • 双向链接：输入 [[ 即可引用其他笔记，右侧反向链接面板自动汇总引用关系，让想法彼此串联；
  • 标签网络：标签自动聚合为可缩放的关系图谱，从任意一篇笔记出发，都能长出一片相关主题；
  • 毫秒级检索：基于 SQLite FTS5 的全文搜索，千篇笔记内定位关键词不超过 50 毫秒；
  • 离线可用：基于 Tauri 打包为原生应用，安装包不足 10MB，没有网络也能完整写作。

设计与迭代

界面沿用本站「素雅纸感」的审美：暖纸白底色、衬线标题、苔藓绿作为唯一的点缀色。前两版把工具栏铺满了整个屏幕，第三版忍痛砍掉一半按钮，只留下「新建、搜索、标签」三个入口——写作不该被按钮打扰。

目前苔原笔记仍在每周迭代，已陪伴 200 余位内测用户写完各自的第一份长稿。欢迎在仓库提 Issue 反馈问题，也欢迎写信告诉我你的写作习惯——下一版的功能清单，由使用它的人决定。
